
Betriebsystem:	Debian 12
	Alle anderen Linuxvarianten werden hier nicht explicit supported, da es bei den Paketen und deren Abhängigkeiten
	zuviel Pflegeaufwand bedeutet.


Resourcen:
	- 16 GByte RAM
	- 200 GByte freier Festplattenspeicher
	- CPU mit mind. 8 Kernen (dauert sonst ewig)


Installation notwendiger Packete:

	Falls notwendig (z.B. in Dockercontainern oder auf Serverinstallationen, wo es fehlt).
	DEBIAN_FRONTEND ist notwendig wenn Timezone Pakete installiert und konfiguriert werden sollen. Diese erfordern normalerweise eine Nutzerinteraktion.
	Dort wo das nicht möglich ist, folgendes installieren:

DEBIAN_FRONTEND=noninteractive apt-get install -y --no-install-recommends tzdata

apt-get install -y  python3 python3-pip python3-distutils-extra python3-standard-pipes \
                        python-is-python3 \
                        libssl-dev libncurses5-dev unzip gawk zlib1g-dev subversion \
                        nodejs git build-essential devscripts debhelper ruby \
                        gcc-multilib flex gettext curl wget time rsync jq tmux vim \
                        pkg-config bison flex bc lzop swig \
                        && apt-get clean

# install python2.7 for openwrt 18 targets
echo "deb http://archive.debian.org/debian/ stretch contrib main non-free" > /etc/apt/sources.list.d/debian-openwrt18-packets.list; \
    apt update && apt install -y python2.7
